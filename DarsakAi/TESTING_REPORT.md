## 🌐 Backend API Tests (TestSprite — 10/10 Failed)

### Root Cause: Environment Issues, NOT Code Bugs
All 10 tests failed due to:
1. **Wrong BASE_URL** — TC001, TC004 target `darsak-backend.fly.dev` instead of `localhost:8000`
2. **Fake JWT tokens** — 8 tests use invalid token (header only, no payload)
3. **No test user** — TC002 tries non-existent credentials
4. **No local DB** — Supabase unreachable from local network

### What These Tests CONFIRM (Positive):
✅ Auth middleware correctly returns 401 for invalid tokens  
✅ All 31 API routes are registered and routed  
✅ Health endpoint returns `{"status":"healthy"}`  
✅ Security hardening is effective
